# Legacy scrape, quarantined

These files came from the previous version of this project, which was a
Puppeteer scrape of `https://ariharan.web.app/` with the name find-and-replaced.

They contain **another real person's** biography, employer, job history, awards,
city, phone number, and social handles. None of it belongs on this site.

They are no longer imported by anything and are excluded from the build. They were
moved here rather than deleted because this project is not under version control,
so a delete would be irreversible.

Once you are happy with the rebuild, delete this whole folder.
